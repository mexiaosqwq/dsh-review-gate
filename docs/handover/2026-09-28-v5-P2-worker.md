## 实现层自主决策（偏差披露）

1. **Config optional 表达**：派令按 zod 习惯写 `.optional()`，本仓实际是 schemastery（类型 `Schema<string,string,'plain'>` 无该方法）→ `.required(false)`（SetRequired<Mode,false> → 允许缺省），语义等价
2. **assemble 收据的 armed 判定**：`context.agent?.id` 缺失时无法定位单 agent state → 判定用「任一 state 有 pendingReview」——多 agent 场景任一 armed + 无 agent 身份 = 闸门可能停摆，行即警报无需精确归因（派令语义兼容）
3. **2b 补 1 测试用例**（合同未点名）：fakeCtx emit assemble 双路径（无 agent id → degraded 落行；带 agent id → 不落行）——静默失效可观测性需要验收证据
